Before you start

Ten minutes. Read the safety rules once, then do two quick checks.

It's a live store. The client's shop is trading on its current theme. You build in a draft theme called Memo, which customers can't see.
  • Only ever edit the Memo theme: Online Store › Themes › Memo › Customize. Never press Publish, and never open the live theme's editor.
  • safe Uploading files: every file in the kit starts with ldt26-, so nothing clashes with the client's files. Never use the Replace option on an existing file.
  • safe Creating new menus. The live theme only shows the menus it already uses. Never edit or delete an existing menu.
  • changes the live site Collections, collection images and products are shared by every theme. Don't create or edit any until step 10 (after the client says yes).
  • Press Save (top right of the editor) at the end of every step.
How each step works
  1. Files: the step's folder (same number) has everything it needs, and you can also download each file here.
  2. Settings: type or copy each value into the setting with the same name. If Shopify words a setting slightly differently, match it by meaning.
  3. Custom CSS: scroll to the bottom of the section's settings, find Custom CSS, click Copy CSS here and paste. Don't edit it. It's been tested on the theme, character for character, and fits Shopify's limit.
  4. Check: compare with the picture under What it should look like, or with the prototype.
EditorOpen the right theme and check Save works. Online Store › Themes: the Memo theme is under the live one. Click Customize on Memo (check the editor's top bar says Memo). Click Announcement bar, change a letter, press Save, then change it back and Save again. If it won't save, stop and tell Luke.
EditorFind Courier New. Theme settings › Typography › Body text › Font › Change: search for Courier New. It's in Shopify's font library, so it should be listed.
Sidekick (optional): Shopify's AI assistant can change theme settings for you. In the theme editor press ⌘ + . (or click the Sidekick icon), paste one purple prompt at a time, and check what it proposes before you accept. Then check the values against the table and press Save: Sidekick doesn't save for you.

  • If it can't do something (often picking files, rich-text links or Custom CSS), do that part by hand.
  • If it changes the CSS at all, discard that and paste the CSS box by hand.
